# Likya Pay: Proje Yol Haritası (Versions & Phases)

Bu proje, Likya Pay sisteminin modern, mobil uyumlu ve React tabanlı bir SPA (Single Page Application) olarak yeniden inşa edilmesini kapsar.

## Toplam Tahmini Süreç: 4 Faz (Versiyon)

### Faz 1 (v1.0 - Frontend Beta): Kullanıcı Arayüzü (UI/UX) Dönüşümü
**Hedef:** Tüm ekranların görsel tasarımını, navigasyonunu ve etkileşimlerini React ile oluşturmak (Mock Data ile).
*   **Anasayfa:** Banka kurumsallığında tasarım, Vizyon/Misyon, Görsel Sunum, Footer (Yasal bilgiler).
*   **Giriş Sistemi:** Şifre göster/gizle özellikli, güvenli görünümlü giriş modalları.
*   **Admin Paneli (UI):** Dashboard (Grafikler), Kullanıcı Yönetimi arayüzü, Döngü Yönetimi arayüzü.
*   **Kullanıcı Paneli (UI):** Borç/Alacak ekleme formları, belge yükleme arayüzleri.
*   *Durum: Şu an bu aşamadayız.*

### Faz 2 (v1.5 - API Alpha): Backend API Sistemi Oluşturulması
**Hedef:** PHP tarafında gerekli tüm veritabanı işlemlerini RESTful API formatına getirmek.
*   `api/auth.php`: Giriş, Kayıt, Token işlemleri.
*   `api/companies.php`: Firma listeleme, ekleme, güncelleme.
*   `api/transactions.php`: Borç/Alacak kayıtları.
*   `api/cycle.php`: Sirius Döngü Formülü entegrasyonu.

### Faz 3 (v2.0 - Integration): Bağlantı ve Fonksiyonellik
**Hedef:** React Arayüzünü (Faz 1) gerçek PHP API sistemine (Faz 2) bağlamak.
*   Verilerin veritabanından çekilmesi.
*   Gerçek kayıt işlemlerinin yapılması.
*   Dosya yükleme (File Upload) sisteminin aktif edilmesi.

### Faz 4 (v2.5 - Release Candidate): Raporlama ve Güvenlik
**Hedef:** PDF çıktıları, güvenlik önlemleri ve arşiv sistemi.
*   Sistem raporlarının PDF olarak indirilmesi.
*   Geçmişe dönük arşiv sorguları.
*   Son kullanıcı testleri ve hata ayıklama.

---

**Not:** Şu an **Faz 1**'i başlatıyoruz. Sitenin tamamı tek bir sayfada çalışan modern bir Web Uygulamasına (React App) dönüşecek.
